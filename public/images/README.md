# Add your own website images here

The website is already coded to look for these exact filenames in this folder. You do not need to edit any source code to use your own images. Copy your image files here and keep the names exactly as shown:

- `hero-salon.jpg` : wide, welcoming salon interior used in the homepage hero.
- `signature-facial.jpg` : facial or skincare treatment.
- `silk-press.jpg` : hair treatment or finished hairstyle.
- `veil-manicure.jpg` : manicure or nail treatment.
- `brow-shape.jpg` : brow treatment or beauty portrait.
- `studio-detail.jpg` : calm self-care/editorial image in the quote section.

Until you add a file, the website uses a remote demo fallback photo. Once the local file exists, it is displayed automatically. This lets you test the website immediately and add licensed images later.

Use images you own or have permission to use. Avoid third-party logos and copyrighted luxury-brand campaign images. Recommended size: 1200–1800 px on the long edge, compressed JPEG or WebP. If you use WebP, change the filename to match the extension you choose and update the `src` mapping in the corresponding component, or simply keep the requested `.jpg` filenames.
